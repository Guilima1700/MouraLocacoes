Moura Locações
Site institucional moderno e responsivo desenvolvido para a Moura Locações, empresa de locação de equipamentos para construção.

Sobre o projeto
O projeto apresenta a Moura Locações de forma profissional, facilita o contato pelo WhatsApp e organiza os principais equipamentos, diferenciais e canais de atendimento da empresa.

A interface foi criada com foco em:

Clareza na apresentação da empresa.

Solicitação rápida de orçamento.

Experiência mobile-first.

Acessibilidade e navegação por teclado.

SEO básico e HTML semântico.

Animações leves e respeitosas.

Componentização e manutenção simples.

Tecnologias
React

TypeScript

Vite

CSS moderno

Lucide React

Intersection Observer API

Instalação local
Clone o repositório:

bash
git clone https://github.com/Guilima1700/MouraLocacoes.git
Entre na pasta:

bash
cd MouraLocacoes
Instale as dependências:

bash
npm install
Inicie o servidor de desenvolvimento:

bash
npm run dev
Abra no navegador o endereço exibido pelo Vite, normalmente:

text
http://localhost:5173
Build de produção
Para validar a compilação:

bash
npm run build
Para visualizar a versão compilada localmente:

bash
npm run preview
Assets
As imagens utilizadas por caminhos como /assets/entrega.jpg devem estar dentro de:

text
public/assets/
Se uma imagem aparecer quebrada, confira se o nome do arquivo e sua extensão são exatamente iguais aos utilizados no código.
